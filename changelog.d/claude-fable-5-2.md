## vi
### Thêm mới
- **Model Claude mới tự hiện trong trình chọn model.** TTTOS đọc thêm danh mục model mà Claude Code tải về từ Anthropic, nên model vừa ra (bản CLI đang cài chưa ghi sẵn tên) cũng hiện ngay, không phải chờ bản TTTOS mới ghi thêm tên.

## en
### Added
- **New Claude models show up in the model picker on their own.** TTTOS also reads the model catalog Claude Code downloads from Anthropic, so a model released after the installed CLI was built appears right away instead of waiting for a TTTOS release to add its name.
