## vi
### Thêm mới
- **Grok 4.7 có trong trình chọn model.** TTTOS đọc danh sách model thật từ Grok CLI, nên model mới của xAI hiện ra mà không cần chờ bản TTTOS mới. Model mặc định của Grok chuyển sang grok-4.7.

## en
### Added
- **Grok 4.7 is in the model picker.** TTTOS now reads the live model list from the Grok CLI, so new xAI models appear without waiting for a TTTOS release. The default Grok model is now grok-4.7.
