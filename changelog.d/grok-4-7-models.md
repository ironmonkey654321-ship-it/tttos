### Thêm mới
- **Grok 4.7 có trong trình chọn model.** Javis đọc danh sách model thật từ Grok CLI, nên model mới của xAI hiện ra mà không cần chờ bản Javis mới. Model mặc định của Grok chuyển sang grok-4.7.

## en
### Added
- **Grok 4.7 is in the model picker.** Javis now reads the live model list from the Grok CLI, so new xAI models appear without waiting for a Javis release. The default Grok model is now grok-4.7.
